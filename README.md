# Merge Cats Defender

A 2D merge-based tower defense game developed using **Godot Engine** for Android.

Players strategically place and merge cat defenders to create stronger units, survive waves of zombies, earn rewards, unlock upgrades, and progress through multiple levels.

---

## Features

- Merge identical cat units to create stronger defenders
- Multiple cat upgrade tiers
- Diverse zombie enemy types
- Wave-based gameplay
- Skill system with consumable abilities
- Upgrade and progression system
- In-game shop
- Multiple levels and environments
- Win/Lose game states
- Pause menu and settings
- Mobile-friendly controls
- Save and load player progress

---

## Tech Stack

- **Engine:** Godot Engine 4.7
- **Language:** GDScript
- **Platform:** Android
- **Graphics:** 2D

---

## Gameplay

- Place cat defenders on the battlefield.
- Merge identical cats to unlock stronger versions.
- Defend the wall against incoming zombie waves.
- Earn coins by defeating enemies.
- Upgrade cats and unlock new abilities.
- Complete levels to progress through the game.
